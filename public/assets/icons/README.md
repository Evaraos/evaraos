# EvaraOS Symbol System

This folder is the source of truth for all EvaraOS icons.

## Structure

- `system/` — navigation, module, and action icons.
- `brand/` — official EvaraOS brand symbols.
- `animated/` — motion-ready icon metadata and animated variants.
- `legacy/` — temporary holding area for retired icons before cleanup.

## Rules

- SVG/vector-first.
- Red, white, and black brand palette.
- Same optical weight, spacing, and geometry across the app.
- No third-party icon set should be introduced here.
