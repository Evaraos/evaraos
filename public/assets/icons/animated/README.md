# EvaraOS Motion Icons

Sprint 2 Phase 2 adds motion behavior to the EvaraOS Symbol System.

## Motion principles

- Subtle, premium, and fast.
- Hover and tap animations should confirm intent without feeling playful.
- Circular icons can rev/rotate.
- Loading, progress, sync, and orbit icons may loop.
- Navigation icons animate only on interaction.
- Respect `prefers-reduced-motion`.

## Motion families

- `build` — panels assemble, used for dashboard/workspace.
- `connect` — nodes link together, used for leads/customers/team.
- `pulse` — soft glow, used for notifications/AI/status.
- `orbit` — circular revolution, used for loading/fabric/progress.
- `shine` — glass sweep, used for security/brand studio.
- `grow` — bars or progress grows, used for analytics/reports.
